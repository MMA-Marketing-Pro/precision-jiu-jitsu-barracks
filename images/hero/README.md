# Hero / Banner Images

Place hero background images here — these are the full-bleed photos behind each page's top section.

- **Recommended:** Landscape orientation, minimum 1920×1080px, JPG or WebP, action or facility-wide shots
- **Files referenced by the site:**
  - `hero-home.jpg` — homepage hero (most important; make this the strongest shot)
  - `hero-about.jpg` — About page header
  - `hero-programs.jpg` — Programs page header
  - `hero-instructors.jpg` — Instructors page header
  - `hero-schedule.jpg` — Schedule page header
  - `hero-contact.jpg` — Contact page header
- **Composition tip:** Leave some negative space on the left third of the image — that's where the headline sits, and a directional scrim will darken that area. A wide action shot with the subject on the right reads best.
- **Swap:** Each hero `<img>` in the HTML has a matching `data-local` attribute — update the `src` to the local path once real photos are in place.
