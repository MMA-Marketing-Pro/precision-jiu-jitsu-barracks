# Logo

Place the Precision Jiu-Jitsu / The Barracks logo here.

- **Filename:** `logo.png` (or `logo.svg`)
- **Recommended:** SVG or PNG with transparent background, minimum 400px wide
- **Swap:** Once the file exists, the `<img src="images/logo/logo.png">` tag in the navbar will render it automatically (the current `onerror="this.style.display='none'"` handler will no-op when the image loads successfully).
- **Remove the text fallback:** Once the real logo is in place, you can remove the `<span class="nav-brand-mark">` and `<span class="nav-brand-text">` blocks from every HTML file if you want logo-only branding.
